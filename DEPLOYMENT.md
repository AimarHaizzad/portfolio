# How to Deploy Your Portfolio

## Quick Deployment Options

### Option 1: GitHub Pages (FREE & EASY) ⭐ Recommended

**Steps:**
1. Create a GitHub account at https://github.com (if you don't have one)
2. Create a new repository named `portfolio` or `aimar-haizzad-portfolio`
3. Upload all your files (index.html, styles.css, script.js)
4. Go to Settings → Pages
5. Select `main` branch and `/ (root)` folder
6. Your site will be live at: `https://yourusername.github.io/portfolio`

**Time:** 5-10 minutes

---

### Option 2: Netlify (FREE & EASIEST) ⭐⭐

**Steps:**
1. Go to https://netlify.com
2. Sign up (free)
3. Drag and drop your entire `Sites` folder
4. Your site is live instantly!
5. You'll get a URL like: `https://random-name-123.netlify.app`
6. You can customize the URL in settings

**Time:** 2 minutes

---

### Option 3: Vercel (FREE)

**Steps:**
1. Go to https://vercel.com
2. Sign up with GitHub
3. Import your repository
4. Deploy - it's automatic!

**Time:** 3 minutes

---

## What URL to Give Your Hiring Manager?

After deployment, you'll get a URL like:
- `https://yourname.github.io/portfolio` (GitHub Pages)
- `https://yourname.netlify.app` (Netlify)
- `https://yourname.vercel.app` (Vercel)

**Just send them this URL!** They can open it in any browser.

---

## Recommended: Netlify (Easiest)

Netlify is the fastest and easiest option. No Git knowledge needed!
